## About the author

Bartosz Osiej builds systems by day — Rust, eBPF, compilers
([@BartoszOsiej](https://github.com/BartoszOsiej)) — and writes horror by
night. The patience required for kernel-level debugging turns out to be the
same patience that slow-burn dread is made of.
